## 📋 Overview

**Urdu YouTube Thumbnail Maker** is a free, open-source web application designed for content creators to craft stunning YouTube thumbnails with native Urdu text support. No complex design software needed—just your browser!

## ✨ Features

- 📝 Real-time Urdu text editing with RTL support
- 🎨 5 professional Urdu fonts (Jameel Noori, Nafees, Alvi, Mehr, Standard)
- 🎯 Text customization: size, color, effects, outline
- 🌈 Background: solid colors or custom image uploads
- 🎭 Adjustable background dimming (0-90%)
- 📏 YouTube-optimized 1280×720px HD output
- 🔄 Live preview with instant updates
- 💾 Download as high-quality PNG
- 📱 Mobile-friendly interface
- ✅ 100% free, no signup required

## 🚀 Quick Start

### Try Online
👉 **[Launch Live Demo](#)** - Open in any browser

### Use Locally

#### Option 1: Direct
`ash
git clone https://github.com/jamamjadalone/Urdu-Thumbnail-Maker.git
cd Urdu-Thumbnail-Maker
# Double-click index.html
`

#### Option 2: Local Server
`ash
# Python 3
python -m http.server 8000

# Or Node.js
npx http-server
`

## 📚 How to Use

1. **Enter Urdu Text** → Type in the text area
2. **Select Font** → Choose from 5 Urdu fonts
3. **Customize** → Adjust size, color, effects, background
4. **Preview** → See changes in real-time
5. **Download** → Get 1280×720px PNG

## 🛠️ Tech Stack

- **HTML5** + **CSS3** + **Vanilla JavaScript**
- **html2canvas** - Canvas rendering
- **Urdu Fonts** - Professional TTF fonts
- **Mobile-first** - Responsive design
- **No dependencies** - Zero external JS libraries
